1. Executive Summary (Non-Technical)

Crescelo is an enterprise-grade customer engagement and workflow automation platform. It empowers businesses of any size to instantly transform their static documentation, product catalogs, service menus, and recorded media into an autonomous, 24/7 AI business assistant. The assistant interacts with prospective clients and existing customers naturally across web, mobile, WhatsApp, and Telegram.

Core Business Value
Crescelo bridges the gap between generic AI models and proprietary corporate knowledge. It guarantees that automated customer conversations are strictly grounded in your actual business policies, verified pricing, and operational hours, while cutting ongoing platform software fees to near zero.

Key Business Problems Solved

Elimination of Support Backlogs

Answers repetitive customer inquiries instantly around the clock, handling peak volume without increasing staff overhead or sacrificing answer quality.

Autonomous Lead Capture

Identifies high-intent prospective customers during conversation and collects names, emails, phone numbers, and service needs directly into a centralized CRM pipeline.

Zero-Conflict Appointment Booking

Enables clients to schedule appointments directly inside the conversation with real-time double-booking prevention, calendar links, and automated email confirmations.

Seamless Human-in-the-Loop Takeover

When customers ask for a human specialist, human agents can claim the conversation from a unified dashboard. The AI gracefully pauses its responses.

Strategic Financial Advantages

  • Zero Mandatory AI Subscription Cost: Local vector calculations run on-premise/on-server, eliminating monthly third-party vector database and embedding fees.
  • Bring Your Own Key (BYOK) Flexibility: Use existing corporate accounts with OpenAI, Anthropic, Google Gemini, Groq, or self-hosted open-source models (Ollama).
  • Rapid Deployment: Embed onto any website using a single copy-paste script tag or a one-click WordPress plugin.

1. Hybrid Retrieval-Augmented Generation (RAG)

To achieve maximum retrieval accuracy across arbitrary business domains without incurring external per-query API costs, Crescelo employs a hybrid dense/sparse retrieval pipeline:

  • Local ONNX Dense Embeddings: Generates 384-dimensional dense vector embeddings directly on CPU via @xenova/transformers using the Xenova/bge-small-en-v1.5 model.
  • Sparse Keyword Engine: Executes full-text search with morphological stemming, stop-word removal, and domain synonym clustering (pricing, scheduling, medical, SaaS terms). Short terms enforce word boundaries () to eliminate false subword triggers (e.g. "fee" vs "coffee").
  • Reciprocal Rank Fusion (RRF): Merges ranked vector candidate lists with sparse keyword candidate lists using standard RRF (constant k=60), ensuring exact SKU/name matches and conceptual semantic matches both receive high ranking.
  • Dual-Query Gating: Conversational turns (greetings, confirmations, slot-filling) are classified via heuristics to skip unnecessary vector search. Multi-turn follow-ups are contextually condensed before embedding.

2. Multi-Format Extraction Engine

  • PDF Documents: Extracted via unpdf with structure-aware text layout parsing.
  • Microsoft Word: mammoth parses .docx archives while preserving document hierarchy and headings.
  • Tabular Spreadsheets (CSV): Parsed with csv-parse into semantic record serialization ([Record #N] Column: Value | ...) so each row retains full context in vector space.
  • Hierarchical JSON: Recursively flattened into structured key-value property paths.
  • Optical Character Recognition: tesseract.js handles text extraction from uploaded images.
  • YouTube Media: youtube-transcript extracts multi-lingual captions with streaming audio transcription fallback.

3. Security, Authorization & Multi-Tenant Isolation

  • Workspace Boundary Enforcement: Every database query and cache partition is strictly scoped by workspaceId. Cross-tenant reads and mutations (BOLA/IDOR) return 403/404.
  • Role-Based Access Control (RBAC): Hierarchical roles (owner, admin, support_agent, billing_manager, viewer). Audit trails and member elevation are restricted strictly to workspace owners.
  • Visitor Capability Tokens: Public visitors communicate via signed HMAC tokens, preventing unauthorized eavesdropping or injection into stranger conversations.
  • Cryptographic BYOK Vault: Third-party provider API keys are encrypted at rest using AES-256-GCM with authentication tags.
  • SSRF Mitigation: Outbound webhook targets and SMTP servers are screened against private IP ranges and loopback addresses via validateSafeExternalUrl.
  • Script Injection Defense: Third-party tracking tags (Google Analytics 4, Meta Pixel) undergo strict regex whitelisting and are injected via safe textContent nodes.

4. Omnichannel & Communication Pipeline

  • Embeddable Web Widget (widget.js): Standalone zero-dependency bundle wrapped in a closed Shadow DOM to prevent host website CSS collision. Streams tokens via Server-Sent Events (SSE).
  • Meta WhatsApp Cloud API: Processes incoming message webhooks with HMAC-SHA256 signature checks, deduplicates deliveries using wamid caches, and honors live human takeovers.
  • Telegram Bot API: Validates webhook secret headers, deduplicates incoming update_id events, and suppresses bot auto-replies when a human agent is active.
  • Concurrency Mutex Booking: Double-booking prevention via Postgres unique constraints and memory mutexes, with iCal feed generation and automated confirmation emails.
