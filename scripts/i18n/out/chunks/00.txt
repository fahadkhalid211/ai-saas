38	How to add an AI assistant to WordPress
39	In the Crescelo dashboard open your assistant, then Overview and "Add to website" (or the Deploy button in the top bar). Copy the one-line script. It already contains your assistant ID and the correct address; the example below shows its shape.
40	Install a snippet plugin such as WPCode or Insert Headers and Footers. Create a new snippet, choose "HTML", paste the script, set the location to "Site Wide Footer" and save. This survives theme changes and works with any page builder.
41	Open your page, view the page source (Ctrl+U) and search for "widget.js". If it is there, the chat bubble appears in the bottom corner within a second or two. If not, the script was not saved on that page or the cached copy is old.
